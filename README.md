# Jutwood site

Landing, privacy and support pages for **Jutwood**, a balance game for iPhone: beavers stack sawn planks out over a
river, and the stack tips into the water when the weight above a plank no longer sits over it.

Live at https://nguyenvanlamm.github.io/jutwood-site/ (GitHub Pages from `main`, no build step).

- `index.html`: landing page
- `privacy.html`: App Store privacy policy URL
- `support.html`: App Store support URL
